点击展开 ▾
社会实践
├─ 商业性实践　→ 文旅产品 / 影视剧本 / 文化产业规划 / 创意街区设计
├─ 教改性实践　→ 以教师／学生为中心 · 讲授式／建构式 · 技能培训
└─ 公益性实践　→ 情感倾诉（反精神贫困）/ 自我疗治 / 图书馆 · 文艺演出

商业性：创意街区、创意阶层、文化产业规划、文创产品深加工——创意写作直接进入产业链。

教改性（教育性）：重心从「教师中心」转向「学生中心」，方法从「讲授式」转向「互构式」，并向下做写作技能培训。

公益性：公共图书馆与公益讲座、线上线下公共社区、文学进社区／工厂／田间；帮助群众写回忆录、家族史、口述史，开发文学的社会治愈与自我疗治功能——这一条正对「反精神贫困」。

西北大学创意写作的公益方向（写作疗愈、口述史、文学进社区）就在这一支上。答本校材料题时把这一点写进「社会实践」，比空谈版图更得分。

「版图」一词的用意 · 收束句
论述结尾
点击展开 ▾
两层用意（背这两句就够）

① 暗含创作主体的主动性，展现学人积极探求学科疆域与边界的努力；

② 以中国化版图表明我国创意写作与西方的关联性与区分度。

为什么不用「体系」而用「版图」

「体系」是封闭的、已完成的；「版图」是开放的、还在扩张的。用版图，等于承认创意写作在中国尚未定型，正由一群人边做边画——这既是事实判断，也是一种学科姿态。

1. 中国化创意写作的版图分哪三板块？末句四字是什么？
知识探索、文体写作、社会实践。总纲四字：研究、教学、创作、服务。
2. 知识探索包含哪四支？
创意写作理论（核心概念界定／具体理论问题）、创意写作简史（西方／中国发展史）、创意写作教学法（思维训练／工坊制教学）、鉴赏与批评（基于创作论的批评／基于创作的鉴赏）。
3. 公益性与商业性实践的分野在哪？
商业性面向产业与市场（文旅产品、影视剧本、文化产业规划、创意街区）；公益性面向不能被市场支付的人群（空巢老人、留守儿童、有心理缺陷者），靠情感倾诉、自我疗治、图书馆与文艺演出兑现社会治愈功能，本质是反精神贫困。
4. 为什么说「版图」比「体系」更准确？
体系是已完成、封闭的；版图是开放、仍在扩张的。用版图既暗含创作主体的主动性（学人在探求学科疆界），又能标示中国创意写作与西方的关联性与区分度。
