新历史小说

这些作品以对传统历史的重新述说和新鲜的叙述视角与手法而区别于「传统的现实主义历史小说」。小说的作者以转型后的先锋派作家和致力于拓展题材的新写实小说家们为主，其创作的最大特征是不再把自己的小说作为演绎「官方历史」的工具，而是从某个角度对史有实录或乏人问津的往事做出种种设想，表现出解构历史的强烈愿望以及以现代哲学思想认识历史的新观念。这种重新审视历史的思想方法，被称为「新历史主义」，体现这种思想的作品被称为「新历史小说」。

代表作有陈忠实《白鹿原》、莫言《红高粱》、叶兆言《夜泊秦淮》系列。

★ 与旧历史小说的区别（五点）

1. 小说主题强调从正史到野史；
2. 思想观念从民族寓言到家族寓言；
3. 叙事角度强调历史的虚构叙事；
4. 人物形象从红黑对立到中间灰色色域；
5. 小说语言表征从雅语到俗语。

答题口诀：主题野化 → 观念家族化 → 叙事虚构化 → 人物灰色化 → 语言俗化。

魔幻现实主义

魔幻现实主义指的是 20 世纪中期拉丁美洲小说创作中的一个流派。魔幻现实主义是通过「魔法」所产生的幻想来表达生活现实的一种创作方法。魔幻是手段，反映生活现实是目的。本世纪 60 年代，拉丁美洲小说创作中魔幻现实主义形成热潮，以马尔克斯的长篇小说《百年孤独》为标志。

一、基本特征

1. 「变现实为幻想而不失其真」

2. 现实与魔幻结合，将超自然现象（如鬼魂、魔法、奇幻事件）自然地融入现实场景，使读者分不清虚幻与真实。

3. 本土文化根基：深深扎根于拉丁美洲的印第安神话、民间传说和宗教习俗，展现独特的魔幻地域文化。

4. 批判现实功能：通过魔幻手法揭示社会现实，如殖民、独裁、政治迫害、贫困等问题，兼具文学性与社会性。

二、艺术手法

1. 象征与隐喻：用奇幻意象隐喻社会现象，如《百年孤独》中带猪尾巴的孩子象征畸形社会。

2. 时空交错：打破线性时间，过去、现在、未来交织，增强叙事的魔幻感。

3. 意识流与内心独白：借鉴西方现代主义，深入人物内心世界，展现复杂情感。

三、在莫言创作中的体现

莫言将魔幻现实主义与高密东北乡的民间文化、神话传说、地方史融为一体，形成「东方的魔幻现实主义」。他自称是「一个讲故事的、一个高密东北乡的说书人」。

《红高粱家族》故事梗概（真题）
故事梗概·口述
点击展开 ▾
📌 提纲 3：简单背一下，能用自己话讲出主要内容即可。
一、基本信息

《红高粱家族》（包括《红高粱》《高粱酒》《狗道》《高粱殡》《奇死》5 部）小说均以「高密东北乡」的「我爷爷」、「我奶奶」等系列人物为主人公，其原形以「红高粱」为背景、以「我爷爷」为线索、以「高密东北乡」为背景，其原形为「我奶奶」的抗日故事。故事被莫言作为其小说的原发地。

二、故事梗概

· 一九三九年古历八月初九，豆官跟着名满天下的传奇英雄余占鳌的队伍去胶平公路伏击日本人的汽车队。

· 十多前年，余占鳌当轿夫的时候同戴凤莲小姐结过婚：戴凤莲的父亲把她许配给了麻风病的儿子，余占鳌就查了蒋家村的酒子。轿子里的戴凤莲，当时戴凤莲带着一把剪刀——剪死了单家的单扁郎，在就要下葬的时候，她剪了单家的婚车。戴凤莲在回门的路上，余占鳌和她相遇在蛤蟆坑里。两人正欲做那「野合」之事，戴凤莲又壮着胆子走进了高粱地，她的父亲和儿子都被「我爷爷」给「我奶奶」送走了。戴凤莲生下了儿子豆官，三日后，单家的单廷秀和戴凤莲的舅舅，因为戴凤莲在高粱地里被人抬走了，死在单家的酒坊里。单家父子已被人杀死，死了十多年的麻风病人戴凤莲的父亲，为戴凤莲的故事，被单家的家族的血缘，戴凤莲的葬礼在高粱地里。

· 鬼子来了，日本兵到高密东北乡挨家挨户搜刮。刘氏一家被日本鬼子用刺刀逼着，被拉走，戴凤莲在家中被日本兵强奸了，戴凤莲的丈夫和儿子被日本兵拉走，在胶平公路上被鬼子杀害。戴凤莲和她的恋人余占鳌在家的土炕上，在日本兵的暴行下，激发了强烈的抗日斗志。

· 余占鳌在胶平公路上袭击日本兵，戴凤莲为抗日队伍的伏击做出了英勇的牺牲，余占鳌在袭击中受了伤，他们被日本兵追杀。

· 在戴凤莲的牺牲后，余占鳌组织队伍去胶平公路上袭击日本兵，他们打死了不少日本兵，也付出了沉重的代价，戴凤莲在高粱地里流尽了最后一滴血。余占鳌站在高粱地埋伏的土坑的故乡，太阳的光辉照着一方幸福的高粱，作者用「我」的叙述，把「我爷爷」的故事写了出来。

余占鳌（土匪式英雄）
人物形象
点击展开 ▾
📌 提纲 4：简单背一下。他是「土匪式英雄」的典型。
余占鳌（土匪式英雄）

高密东北乡的土匪余占鳌的形象，他的性格，他的一生的遭遇。他杀死单家的麻风父子，与「我奶奶」的感情纠葛，「我爷爷」的抗日故事，他的土匪队伍，都是「我爷爷」的形象的展开。

性格的复杂性：「我爷爷」是一个「土匪式的英雄」，他既是「我的爷爷」，也是「我父亲的父亲」，更是一个「充满了原始野性的、生命力强悍的」形象。他的身上充满了「强悍、残酷、豪爽、率直、粗野、风流」的性格特征。

「高密东北乡」——这块黑土地孕育了余占鳌这样一个「普通土匪式的英雄」。余占鳌既是历史的「我爷爷」，也是一个「有血有肉的形象」。在他的身上，既有「原始野性的生命力」，又有「传统伦理道德」的约束。

红高粱精神（了解，不背）

（1）一是敢爱敢恨、蔑视礼法传统。「我爷爷」、「我奶奶」虽然爱得粗野，却也爱得真诚，他们无视传统道德的约束。「我爷爷」的「红高粱精神」，是一种「原始生命力」的张扬，是对传统礼法的蔑视。

（2）二是敢作敢为的土匪精神，远非政治范畴。在抗日战争时期，国难当头的时刻，「我爷爷」和他的土匪队伍，以「土匪」的身份，以「草莽英雄」的形象，进行着「抗日」，他们身上有着「民间的生命力」。

总之：余占鳌的「土匪英雄」的形象，成为了那个时代的人物性格的一种「非主流」的叙事，作者将「民间文化」的「野性」融入到了「民族历史」的叙事中，成为了「民间历史」的「野史」的重写。

点击展开 ▾
🔥 提纲 5：全页最重点。以下五点＋补充，构成一道完整论述。
一、以「生命意识」为基调

1. 小说以「我爷爷」为线索，以「我奶奶」的抗日故事为原型，对农民真切的文化心理进行原生态的描写。

通过「红高粱」这一象征意象，真实地再现出北方农民充满原始生命力的生态和原始生命形态。

2. 一方面浓墨重彩地渲染了一种火红的高粱地的民间英雄性格，另一方面则写活了战争这一特殊环境来开掘真正属于农民意识的正负两个侧面。「红高粱」象征着一种原始的生命力与野性的力量。它的生命力的张扬与生命意识的勃发，是作品的一个重要特征。

3. 在《红高粱》中，主人公们无论「我爷爷」「我奶奶」，还是罗汉大爷，中国农民粗犷酷烈、坚忍不拔的抗争意识，在民族危难之际，他们表现得格外充分。他们生活得无拘无束、自由自在，但也因为无拘无束，而充满了原始的野性。在死亡面前，他们没有恐惧，只有对生命的渴望。

4. 在《红高粱》系列中，我们所看到的是战争的血腥与残忍，强权、杀人越货、无所顾忌的土匪，他们一方面被名教纲常所压制，另一方面又以原始的生命本能，对封建礼教和世俗的规范进行了强烈的冲击，这也是人们所说的「红高粱精神」。

5. 在《红高粱》系列中，作者也写出了那些最富生命力的民间文化形态，在生命与生存、原始与文明之间，展现出不同人物性格的复杂与真实。他们有正义感和乡土气息，他们豪爽仗义、快意恩仇，有着坚忍不拔的生命力，这不仅表现了个人性格中的丰富，也从更深广的方面，也体现了勇于抗争、勤劳朴实的民族精神。

二、《红高粱》中交织着思索与反思的复杂意味

1. 它写的是一部批判、但又不同传统的历史事理，写到惨烈之处，作者常藉此一轻松幽默调侃的笔调来写，让读者从字里行间体会深意。

2. 小说营造了一个「我爷爷」的历史：在对历史、生命、人性的思索中，表现出了一种「后现代」的历史观——历史不是单一的、线性的，而是充满了偶然与悖论。

3. 在“我爷爷”的“我父亲”的“我”的叙述中，「我」对祖先的「家族神话」的追寻，表现了对祖先的崇敬，也表现了对「种的退化」的忧思。

三、在现实主义精神中容纳了大量的现代派表现技巧，造成小说创作的新格局

1. 整个《红高粱》充满了浪漫和豪放、张扬的生命力。《红高粱》系列的民间英雄性格，寄托了中国传统文化中「民族精神」的象征。作品的生命主题是对强权的反抗，对生命力的张扬，对生命力的讴歌。

2. 在叙事策略上，《红高粱》以「我」的视角展开，以「我」的讲述反讽历史、解构宏伟叙事，表现了新历史主义小说的特征。《红高粱》的叙事是「非英雄化」的，它把「我爷爷」写成了一个「土匪」，「我奶奶」写成了一个「敢爱敢恨的女人」。

3. 在《红高粱》中，「我」是以回忆来叙述的，作者是让「我」的叙述充满了对历史的解构。作品以「我」的视角，把「我爷爷」、「我奶奶」的故事，讲得充满了个性化的感受。小说中「我」的叙述，是现代的，也是充满「野性」的。

4. 《红高粱》把「历史」与「现实」结合在了一起，把「历史」的野性，变成了「现实」的激情。

四、从叙事策略与语言方式都追求着强烈的「陌生化」效果

1.「以非事事」的方式叙述故事，小说的展开并不依赖事情的发展逻辑，而是由感觉引导、由情绪推动，情节的逻辑被最大程度地淡化，叙述显得自由潇洒而生机勃勃。

2. 叙述人称上将「第一人称」和第三人称混合着使用，叙述者与被叙述者刻意错位融合。这种方式使叙述更加强烈地展现对象的生命，富有感觉。使读者可以形成一种审美距离，叙述者「我」不仅知道关于过去的事情，而且可以自由地超越时间，对当下的叙述发表评论。

3. 穿串的视角和戏剧性的故事，莫言的小说语言富有个性化，其中最具创意的是打破了「过去」的连续性，让一个拟定的叙述者在过去、现在之间穿插跳跃，使生命原始的状态成为当下的一个存在——他往往在叙述中穿插了故事，以感觉和情绪来推动叙述，而且「我」的叙述也是「现在」的，这样的叙述使得小说的「历史」与「现实」相互交织。

4. 语言：天马行空般的、粗犷的、带野性的语境，都体现在多方面，其具体表现是：动词、色彩的奇妙运用，意象、比喻的繁复运用，散漫放纵的抒情，都以丰富的形象和色彩，为语言增色。其语感具有明显的审美个性：
  （1）语音特点——多用叠音词，追求音节的整齐和韵律感，例如：「我爷爷」的「绿高粱，红高粱」，用「高密东北乡」这样的「叠音」来增强语言的表现力；
  （2）词汇运用方面——有大量的「红色」词汇（红高粱、红萝卜、红盖头、红绣鞋），以「红」这一色系为基调，与「高密东北乡」的生命力相呼应；
  （3）句式方面——多采用短句，追求语言的气势和节奏感。

5. 追求最大程度的陌生化。一是「暴力」描写，如「剥皮」的描写；二是「性」的描写，如「野合」的描写，作品里充满了生命的冲撞和生命的张扬，一种生机勃勃的「酒神精神」。
