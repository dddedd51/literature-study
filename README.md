# 文学史资料学习站

独立的 GitHub Pages 静态学习网站。

访问地址：https://dddedd51.github.io/literature-study/

纯 HTML、CSS 和 JavaScript，无需构建。保留 `.nojekyll`，以便发布 `_shared/` 字体及思维导图的 `_vendor/` 依赖。

## 更新

在本仓库目录修改资料后，提交并推送 `main` 分支，GitHub Pages 自动更新。

```sh
git add .
git commit -m "更新学习资料"
git push origin main
```

本仓库使用 GitHub 默认域名，独立于 `marfastudy` 仓库及其自定义域名。学习进度保存在当前浏览器的 localStorage 中。
