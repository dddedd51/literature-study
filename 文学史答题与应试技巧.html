01 / 随手速查考场只抓住这条链

题干要我判断什么 → 我分哪几方面回答 → 每方面有什么证据 → 证据为什么能支持判断

落笔前 30—90 秒

圈出对象、范围、任务、限定。先写一句总判断，再列相互不同的小标题，每点旁边放一处作品细节。

每段 4 个动作

判断 → 细节 → 解释 → 回题。“语言生动、人物鲜明”后面必须说明：哪种语言、哪个动作、怎样形成效果。

题型转换

名解回答“是什么”；艺术题回答“怎么写”；思想题回答“写出什么问题”；比较题同维度对照；演变题按阶段说明“变了什么”。

卡住时

先用确定的作品细节恢复知识。想不起第三点，换叙述、结构、语言等维度检查；完全陌生的专名不能靠字面编定义。

时间底线：按卷面分值给题目设截止点。若全卷 150 分、180 分钟，扣除读卷与检查共 15 分钟，约每分 1.1 分钟；5 分约 5.5 分钟、10 分约 11 分钟、20 分约 22 分钟、40 分约 44 分钟。到点优先保住未答的大题。

02 / 审题先把题目改写成一句任务

例如“论述《西厢记》的故事演变”，任务是交代主要阶段，并解释故事、人物与价值判断如何变化。只写王实甫作品的艺术特色，即使内容正确，也没有完成“演变”。

题干信号主干应写什么常见跑题
艺术特色／艺术成就选最突出的写法：叙述、结构、语言、人物塑造等；说明效果。大半篇写社会背景与主题。
思想内容／形象内涵人物处境、矛盾、价值追求及其意义；用具体行动证明。只说“象征、对比、语言优美”。
比较／异同先定共同维度，每段 A 与 B 对照；异同都答。前半篇背 A，后半篇背 B，没有比较句。
演变／发展／流变阶段 → 文体或内容变化 → 意义；有承接关系。列作者年表，或只写成熟形态。
原因／何以形成因素 + 具体作用路径 + 文学表现。只堆“经济政治文化”名词。
结合／试评／谈认识界定命题、作出判断、拿材料或作品论证，必要时说明限度。背一般概念，漏掉指定作品或材料。

90 秒提纲法：先写“可证明的句子”

  1. 0—20 秒：圈题干限定。是“鲁迅小说”，还是“《故事新编》”？是“内容”，还是“内容与艺术”两个任务？
  2. 20—50 秒：写总判断和 3 个暂定分点。3 点只是便于组织的起点；题干有 4 个必要方面就写 4 点。
  3. 50—90 秒：给每点各放一个例证；没有证据的点先调整，不用空词撑场面。

检验小标题：把作家名换成另一个人，这句话还完全成立吗？如果是，通常太泛。例如把“人物塑造生动”改成“通过不同人物的反应，揭出阿 Q 的等级观念与自我欺骗”，就更接近具体答案。

03 / 段落一个有效论证段怎样长出来

可争辩的判断 + 可核对的细节 + 从细节到判断的解释 + 对题干的回应

薄弱写法：卡夫卡善于运用荒诞手法，具有象征意义，反映了深刻的社会现实。

判断：《变形记》把不可能的事件与日常生活逻辑并置，使“异化”成为可以感知的处境。细节：格里高尔醒来发现自己变成巨大的虫，却仍然焦虑误了上班和火车。解释：身体的灾变没有立刻压倒工作压力，这种反差显示劳动义务已经深入他的自我认识；人先被当作劳动和收入的工具，身体变形把这种关系显形。回题：荒诞因此构成揭示现代人生存困境的艺术方法。

细节来自你的《答题例证卡》相关条目；此处用“虫”概括，避免把译本中的形态描述写成统一的生物学定名。

只有术语，怎样往下写

想起的术语继续追问能落笔的句式
讽刺谁说了什么？他的行动与自我评价有何矛盾？作品让……与……并置，使人物自以为……的判断暴露出……
意识流／时间错位是哪一人物在感知？何种感官或记忆触发了跳转？叙述由……转入……，以心理联想组织材料，使读者感到……
情景交融哪个景物词受到情绪着色？视角怎样变化？……本是外部景物，但……的选词／组合把……心情投射其中。
典型形象独特性格如何与具体社会关系相连？人物在……关系中作出……选择，既显出……个性，也呈现……处境。

举例不是只能引用名句。人物行动、叙述顺序、章节结构、语言反差都可作为证据。记不清原话时准确转述，保留篇名和情境即可；“有学者认为”不能用来掩盖不确定的事实。

04 / 名词解释先给准确边界，再补辨识特征

四格：属什么类别 → 核心含义 → 代表或特征 → 作用或地位。按名词性质取舍，别给每个概念硬编提出者、年代、缺点。

考什么优先写什么
作品：《尤利西斯》作者与体裁 → 主要内容／组织方式 → 关键艺术特征 → 文学史意义。
社团：创造社成立背景与代表成员 → 前期主张及创作倾向 → 后期转向；不要把两个阶段混成一个。
技法：互见法说明同一人物或事件分见于不同篇章 → 相互补充的方式 → 《史记》例证与作用。
风格：沉郁顿挫核心含义 → 内容与表达的关联 → 作品例证；不能只写“忧国忧民”。
完整示范：名词解释“赋比兴”（训练题，非历年原题）

赋、比、兴是中国古典诗歌的重要表现手法，在《诗经》中有广泛运用。赋指铺陈直叙，把事物、情景或感情直接展开；比指以彼物比此物，通过相似性表达所写对象的特点；兴指先言他物以引起所咏之辞，常兼有营造氛围、唤起联想的作用。如《硕鼠》以大鼠比剥削者，《关雎》以雎鸠和鸣引出对淑女的思慕。三者在具体作品中可以交错使用，尤其比兴使物象与情意相联系，对后世诗歌含蓄的抒情传统产生了深远影响。

这段的功能：首句定类别；中间分清三个概念；两个例子显示比、兴区别；末句交代作用。这里写的是表现手法“赋”，不要答成汉代辞赋的文体解释。

训练长度：你的讲义常用约 200 字，可先以 150—220 字检验能否讲清楚；卷面有具体字数时以题目为准。5 分名解若限约 5—6 分钟，不要为凑 200 字挤掉论述时间。

05 / 简答用几个不同方面，直接答完问题

先用 1—2 句总答，主体通常分 3 点，每点写“特征 + 证据 + 作用”。题干要求艺术特色，就让主体保持在艺术层面；思想意义放在解释效果处。

示范设问：简析《故事新编》的创新性。你的《专硕冲刺50天》将其列为 2025 年简答；这里依据现有条目重写，不作为官方答案。

完整示范：《故事新编》的创新性

《故事新编》取材于古代神话、传说和历史，以现代眼光重新组织故事。其创新主要体现在古今交织的叙述方式、人物的重新塑造和多样化的讽刺表达上。

一、古今杂糅，使古代题材获得现实指向。作品保留古代故事的基本轮廓，又把现代生活气息和现实话语带入其中。《理水》在大禹治水故事中写文化山学者的空谈，把实干者与脱离实际的议论者相对照。读者因时代错位而感到滑稽，也由此识别现实中的类似现象，古代题材因而成为批判现实的媒介。

二、重塑英雄与普通人的关系，突破单一的神圣化形象。《非攻》表现墨子奔走止战，同时写他的劳顿和返程遭遇。作品既肯定其担当，又把人物放回有身体负担、有现实阻力的生活处境。理想与日常困顿之间的落差，使英雄具有具体的人间质感，避免把人物写成抽象的道德符号。

三、以反讽、戏拟等方式重审历史叙事。《采薇》通过对伯夷、叔齐故事的改写，把庄严的历史说法与人物的生存处境并置，使读者重新审视既有价值判断。这种处理并非只为逗笑，而是以叙述距离暴露观念与现实之间的矛盾。

因此，《故事新编》的创新在于以新的叙事方式重新解释古代故事，使历史想象、现实批判与人物塑造相互结合。各篇风格有差异，不能把全部作品概括成同一种滑稽讽刺。

拆解：三点分别回答“时代怎样处理”“人物怎样重塑”“叙述如何评价”，彼此不重复。最后一句保留作品差异，避免用“油滑”覆盖全书。

同一份材料，遇到换问怎样改

如果改问“《故事新编》的思想意义”，就把标题换成现实批判、历史价值重审、对人的处境的关切；古今杂糅等写法成为支持这些判断的证据。不能只改开头而原封不动背三段。

06 / 论述与演变论述比简答多的是解释关系

“论述”需要说明事实之间如何相连。演变题尤其要回答后一阶段继承了什么、改变了什么、改变有何意义。这里用阶段作主体，末段归纳总体方向。

资料设问：论述《西厢记》的故事演变（整理页记为 2026 年论述）。对应李凡古代第 316 题“试分析西厢故事艺术形式与思想内容的流变”。

阶段文体线内容线
唐代《莺莺传》文言传奇爱情发生与张生负心；保留为张生辩护的价值立场。
宋代传播鼓子词、转踏等故事进入歌唱与说唱传播，情爱表达得到展开。
金代《董西厢》诸宫调改造人物与冲突，矛头更多指向阻挠婚姻的力量。
元代《王西厢》杂剧舞台冲突与心理刻画深化，肯定有情人的结合。
后续改编南曲等改编随舞台与受众调整；部分版本向礼教规范回摆。
完整示范：怎样把年表写成论述

西厢故事以崔莺莺与张生的爱情为核心，从唐传奇到金代诸宫调、元代杂剧，经历了持续改写。其演变既是文体与传播方式的变化，也是人物关系、矛盾中心和婚恋价值判断的重构。

一、唐代《莺莺传》奠定故事本事。元稹以文言传奇写张生与莺莺相恋而最终分离。作品呈现莺莺的真情与张生的负心，却又通过张生的说辞为其行为辩护。因此，叙事中的爱情经验与士大夫伦理之间存在张力。后来的改编正是在保留相恋故事的同时，逐步改变这种评价立场。

二、宋代改编拓展了歌唱与说唱的表现空间。赵令畤《商调蝶恋花》等作品使西厢故事进入新的文体形式。相较于传奇叙述，歌唱部分更便于铺展人物的情绪与爱情体验。这一阶段的意义主要在传播形态和抒情表现的拓展，不能简单说成已经完成了《王西厢》的价值转变。

三、金代《西厢记诸宫调》对冲突和人物作出关键改造。董解元突破原作格局，使崔、张与红娘同阻挠婚姻的力量形成更鲜明的对立。爱情失败不再主要被解释为女子应受谴责，故事转而肯定青年男女的真情及其争取爱情的行动。篇幅和说唱形式的扩展，也为情节铺陈与人物个性的发展提供了条件。

四、元代王实甫《西厢记》把故事转化为充分展开的舞台冲突。在继承《董西厢》的基础上，作品通过赖婚、拷红、长亭送别等场面，把家庭压力、人物行动与细腻心理结合起来。莺莺对爱情的追求与礼教束缚相互纠缠，红娘则在冲突推进中发挥主动作用。唱词与戏剧情境相结合，使肯定真情的立场获得更强的抒情力量。

此后西厢故事仍在南曲等形式中继续改编，部分改编对其婚恋观作出向传统伦理靠拢的调整。可见，其演变并非单向直线：总体上从叙述故事走向说唱、舞台呈现，从对负心行为的辩护走向对真挚爱情的肯定，但不同传播环境又会带来新的取舍。

为什么这样写：每个阶段同时带出“形式”和“价值”两条线；结尾不重复篇名，而是概括变化。若题目只要求“思想内容流变”，压缩文体部分；若明确止于《王西厢》，后续改编不再展开。

记不清宋代中间环节时，先准确写清《莺莺传》→《董西厢》→《王西厢》及关键变化，再回补已知环节。不要虚构版本、作者和年代，也不要声称这三部就是全部演变史。

07 / 其他常见问法比较用同一把尺，成因写出作用路径

比较题：先给共同基础，每段成对对照

例：“比较李白与杜甫诗歌的艺术风格。”先说明二人都拓展了唐诗的表现力，再选择相同维度。以下是训练提纲，概括主要倾向，不代替两人的全部创作面貌。

比较维度李白：判断 + 例证杜甫：判断 + 例证
抒情方式《将进酒》以夸张与强烈情绪推进，凸显自我精神的张扬。《登高》把羁旅、衰病等处境层层叠合，情感深沉凝聚。
组织材料《梦游天姥吟留别》借梦境、奇想与场景跃迁拓展空间。《石壕吏》以具体场景、人物言语和叙述省略呈现现实矛盾。
语言与表达《蜀道难》的反复咏叹、夸张想象形成强烈声势。《登高》的凝练对偶与层次推进，使景象与身世相互映照。

成段示例：在抒情方式上，李白《将进酒》以夸张和情绪起伏突出自我精神，杜甫《登高》则将羁旅、衰病和孤独层层叠合。二人都抒发强烈情感，但前者偏于喷涌展开，后者偏于凝聚回旋。这种差异是所举作品的主要倾向，不能推出李白没有忧患、杜甫没有豪情。

成因题：不要停在“时代影响了文学”

“市民文化发展 → 城市说话与刊刻的传播条件 → 叙事更重悬念、日常生活与可读性”才是一条解释链。每个因子都要落到可辨认的文学变化；一个宏观背景不能自动解释所有作家、所有文本。

评价题：先界定，再评价贡献与限度

例如评价某创作主张：它针对什么问题 → 带来何种文学变化 → 有什么适用限度。限度必须与题目有关且有依据，不必为“辩证”硬凑批评。题干只问艺术成就时，也不用专开一段缺点。

08 / 知识调用同一个例子，怎样服务不同题干

从你的例证卡、艺术特色表与分科材料中，优先提取“一个判断 + 一处细节 + 一句解释”。下表只列可用方向；换题必须换解释，不能把同一段机械搬过去。

材料可记住的证据题目变化时怎样解释
杜甫《登高》“万里悲秋常作客，百年多病独登台。”问沉郁：解释多重悲感叠合；问炼字：分析“常”“独”的限定作用；问对偶：看对应词语怎样组织空间、时间与处境。不能只凭这两句证明所有声律论断。
《史记》项羽相关篇章鸿门宴的言语与行动；项羽事迹在不同篇章得到补充。问形象：落到性格与行动；问互见法：必须指出跨篇补充关系，不能只概述鸿门宴情节。
鲁迅《故乡》记忆中的少年闰土与重逢时的闰土形成反差，“老爷”的称呼拉开距离。问人物：解释社会处境与隔膜；问叙述：分析回忆和眼前现实的对照；问主题：从关系变化论证精神隔膜。
鲁迅《阿Q正传》受辱后用“儿子打老子”等想法把失败转为心理胜利。问精神胜利法：说明自我欺骗的运作；问讽刺：解释事实与人物自我解释之间的反差。
贾平凹《秦腔》清风街的人事变迁、密集日常细节与引生的叙述。问乡土转型：从生活变化谈文化处境；问艺术：说明琐细生活如何组织成乡村群像。答“贾平凹长篇总体范式”还须补其他作品，不能以一部替全部。
卡夫卡《变形记》身体变形后仍担心上班；家庭关系随着劳动能力的丧失而变化。问艺术：荒诞事件与日常逻辑并置；问异化：人与人的关系受工具价值支配。二者可以相连，但主次随题干调整。
福克纳《喧哗与骚动》不同部分围绕康普生家族，从不同人物与叙述方式展开。问结构：讲多角度、非线性时间与信息互补；问人物意识：讲具体部分的心理组织。不能把全书各部分都说成相同的意识流独白。

回到材料：答题例证卡 · 艺术特色总表 · 完整答案本。挑例子时优先选自己能准确解释的，不追求冷僻。

09 / 考场大脑空白自救先恢复一个小动作，再找回知识

“我现在想不起答案”不等于“我把知识全部忘了”。临时提取困难时，越盯着讲义的原句硬想，越容易停住。你现在要做的是把任务外化到草稿纸，让一个确定细节带出下一步。

最初 90 秒，照这个次序做

  1. 0—20 秒，停一下。双脚放稳，松开握笔的手，缓慢呼气两三次，不刻意憋气。对自己说：“我先找一个确定事实，不用现在想起整篇答案。”
  2. 20—40 秒，抄任务，不抄整题。例如写“《变形记》——艺术特色”；再拆成“怎么写？产生什么效果？”把脑中的“大题”缩成两个小问题。
  3. 40—70 秒，列碎片。不成句也可以：作家、人物、情节、语句、结局。只记确定的内容，不纠结顺序，不先追求三点。
  4. 70—90 秒，连接一条。在一处细节后写“这说明……因为……”。能连上，就从这一点开始写；完全没有可用信息，标记题号先做下一题。

暂时跳题不是放弃这道题。按答题纸规则预留位置并标清题号，在本轮结束或检查预算中回来。不要写到别题规定区域，也不要每隔几十秒又回来看它一次。

四个检索入口：不要同时问自己“我知道多少”

① 人和事

谁做了一件什么事？他为什么做？结果怎样？这最适合人物、小说、戏剧情节。

② 词和句

记得哪一句、哪两个词？情绪是怎样的？景物如何组织？这适合诗词与散文。

③ 前和后

这个作品前后，人物、叙述或价值判断有什么变化？这适合结构与演变题。

④ 同和异

它和我熟悉的邻近作品有什么相同、不同？比较只写可确认的维度，不能替陌生作品补情节。

现场示范：忘了《变形记》的三条特色，只记得“变虫了还怕上班迟到”

草稿先写：变虫＝不可能的事件；怕迟到＝熟悉的生活逻辑；两件事并置＝反差。题目问艺术，先解释这种反差的写法。

《变形记》把荒诞事件放入日常生活的逻辑中。格里高尔发现自己变成虫以后，首先担心的仍包括上班与误车。离奇的身体变化和具体的职业焦虑并置，使读者一方面感到不可思议，另一方面又能辨认熟悉的工作压力。作品由此把抽象的生存压迫转化为具体可感的情境，使荒诞具有揭示现实的力量。

你没有复原讲义，却已经写出一个有证据的论证段。随后若想起家庭态度的变化，可以继续展开人物关系；若想不起，就先留待回补。这个段落只能支撑相应的一点，不能伪装成完整的 20 分答案。

现场示范：忘了“沉郁顿挫”的讲义，只记得《登高》一句

先写“万里悲秋常作客，百年多病独登台”。用自己的话标出：离乡远、常作客、多病、独自一人。然后将这些确定的信息归为“多重身世之悲叠合”，就能写出沉郁一侧的解释。

能写的判断：诗中将空间上的漂泊、时间上的衰老与现实中的病苦、孤独相互叠合，情感因此深厚凝重。还不能直接推出：这两句存在某种你记不清的特殊拗律；如题目同时问“顿挫”，还应从准确记得的章法转折或表达层次继续寻找依据。不能用“感情悲”代替整个风格概念。

分清卡点，选对补救

实际情况当场做法停止什么
知道作品，忘了答案标题回想一处人物行动、叙述变化或语言细节；由证据反推能成立的判断，再检查题干方向。在脑中逐字搜索讲义原句。
只记得时代、流派先写确定的归属；进一步落到已知作品。时代知识只能提示检索方向，不能替代该作家特征。把“现实主义”自动展开成每位作家都一样的三条。
记得两个点，想不起第三个检查已写的是思想还是写法；从结构、语言、人物、叙述中找有证据的新维度。题干要求都已答到时，两点写实也优于重复凑点。把“人物生动”和“形象鲜明”算成两个独立点。
完全陌生的专名只写可确认的分类和信息，标记后跳过，回头再处理。拆字猜学派定义；编作者、年代、代表作。
大题只剩 5 分钟先保证总判断和所有分问都有短答，再给最关键的两处证据及解释，末句回题。从宏大背景重新铺陈，或把全部时间花在第一个分点。

怎样让这套自救在考场上可用

平时随机抽一道已学题，盖住答案，只给自己 90 秒写“任务 + 两个确定碎片 + 一个判断”。如果写不出，就查清到底缺事实还是缺组织方法；下次只补这一缺口。练习目标是缩短从停笔到重新写出有效内容的时间，不要求自己完全不紧张。

最后一遍修改，优先级这样排

漏题漏问 → 明显知识错误 → 只有结论没有证据 → 不清楚的句子 → 字词修饰。把“艺术特色”改成更华丽的词，通常不如补一句“这个细节如何证明该特色”。发现错误按答题要求清楚划改，避免反复涂黑。

10 / 配速先算整张卷，再决定一题写多长

你的题型整理记录近年 647 为名解 4×5、简答 3×10、论述 3×20、材料 40，总计 150 分。以下按180 分钟模拟；这是基于现有资料的训练方案，正式题量、分值和时长以当场试卷为准。

阶段预算从开考起的截止点执行动作
读卷5 分钟第 5 分钟核题量、分问、选答要求，给大题划时间。
名解 4 题22 分钟第 27 分钟约 5—6 分钟/题；第一轮只写确定信息。
简答 3 题33 分钟第 60 分钟约 11 分钟/题，含短提纲。
论述 3 题66 分钟第 126 分钟约 22 分钟/题，先提纲再展开。
材料题44 分钟第 170 分钟读材料、分问与提纲都算在内。
检查10 分钟第 180 分钟漏问、题号、答题区域、知识硬伤。

若模拟中总把材料题拖到最后写不完，可在确认答题位置后先做材料题，再安排其余部分；调整顺序应在整卷训练中验证。上表只是便于执行的一个顺序。

字数必须经过自己的写速检验

旧讲义的“名解约 200、简答约 500、论述约 600、材料约 800—1000 字”相加约为 4900—5100 字，不是每个人都能在思考和审题后写完。先计时完整写一道题，记录“审题 + 提纲 + 正文”实际用时。若超时，先压缩套话和背景，保住必要论点与分析；有明确字数要求时，必须把达到要求的写速练出来。

不要把旧讲义的 9／19／38 当成试卷满分，也不要据此计算每分钟应得几分。时间预算依据题面 10／20／40 等实际分值，讲义数字仅是旧材料中的评分描述。

11 / 相邻题型647 材料题与 853：必须回到给定文本

647 材料题：一句材料，一句解释，一步判断

  1. 把设问拆开：问关系、原因、评价还是创作方法？给每个分问预留位置。
  2. 圈出材料中 2—3 处能支持回答的句意，标注“主张／例证／反面现象”。
  3. 引入所需概念后，用材料推论；每段都能回答“这一点从材料哪里来”。
  4. 结尾回答条件和边界，不只是“我认为很有意义”。

以下为依据你资料中“非虚构写作中真实与虚构的关系”设问设计的示范段，不是原材料全文的标准答案。

训练用材料转述：叙述者会对事实作选择和组织。
概念解释：叙述包含建构，意味着事实通过视角、次序和语言成为可理解的故事。
判断与边界：这不能推出非虚构可以任意捏造人物、事件或引语。作者可以调整呈现顺序、选择描写重心；面对无法核实的部分，应交代来源与不确定性。艺术组织与事实责任需要同时成立。

853 评论：理论名称必须变成分析动作

现有整理记录近年含“理论说明 + 文学评论 + 创作”。如果要求自报理论，就写清核心概念及本题用法；不能仅把副标题换成“新批评视域下”便算使用理论。

例：用叙事学分析《故乡》，应说明“我”的叙述位置、回忆与重逢的时间组织怎样形成闰土形象的反差，进而解释隔膜。不是在开头写“叙事学关注时间与视角”，后文继续复述情节。

853 创作：把题面约束转成可见的行动

若题目要求“具有相反性格的人”，在同一情境里安排两种倾向的拉扯，让选择和后果显示矛盾；不要只用旁白宣布“他既自私又善良”。续写题先承接既有人物、地点、视角与未解决的事件，再推动变化。动笔前定结尾，避免用大半篇幅开场而没有完成故事。

继续查用：材料题答题方式 · 853 备考卡 · 《故乡》文本分析。

12 / 方法验收不要再以“看着都懂”作为完成标准

每次拿一道已学题，做一个12 分钟的小循环：1 分钟审题 → 2 分钟闭卷列提纲 → 5 分钟写最难的一段 → 3 分钟对照资料 → 1 分钟只改最大问题。它是段落训练，不替代完整限时卷。

古代：来自用户材料的改写

“演变”改成“比较《莺莺传》与《王西厢》的婚恋观”。先决定哪段背景删掉，改用哪组对照。

现当代：来自用户材料的改写

以《故乡》为例说明鲁迅怎样通过叙述方式表现人物关系。必须有一条“方式 → 效果”的解释。

外国：来自用户材料的改写

同用格里高尔担心上班的细节，分别写“艺术特色”和“异化主题”的两句判断。

自查，不换算考试分数

是否答全任务？例证是否准确？分析是否真的证明论点？超时发生在想点、找例还是写句子？只记录实际表现。

训练核对方向

古代：从对张生负心的辩护与对真情的肯定、爱情冲突的归责、人物行动等相同维度比较，少写传播史。现当代：回忆／眼前现实的对照 → 少年闰土与重逢闰土的落差 → 关系变化与隔膜。外国：艺术题写不可能事件与日常逻辑的反差；主题题写劳动义务压倒个体处境，显示工具化关系。

完成后隔一天换一个设问重写提纲。能换问且能落到证据，才说明方法开始可用；背出此处句子本身不作掌握证据。

13 / 资料依据保留有效方法，修正机械口诀

旧说法本指南的处理
必须三个论点；少一个最多 12 分没有核实的官方评分依据支持这种固定算式。先覆盖题干，按相互独立的必要方面分点。
开头抄关键词就能防偏题防偏题靠每个分问与主体论证的对应；抄题干不等于回答题干。
不了解作品，可从时代直接推出来时代用于唤回记忆，具体判断仍要靠作品。记忆不足时缩小论断，不把推测写成事实。
只需换理论名就能从鉴赏变评论理论要改变分析问题与解释方式。标题和术语不能代替文本论证。
去年考过今年可放弃现有真题整理只用来识别问法和训练价值，不作排除考点的保证。

  • 专硕冲刺题型整理：查近年题型、分值与设问记录；本次未重验历年原卷。
  • 完整答案本 · 西厢故事流变，及李凡古代第 316 题：用于演变示范。

  • 先秦秦汉分册、完整答案本现当代、外国条目：用于名解、简答与例证内容核对。
