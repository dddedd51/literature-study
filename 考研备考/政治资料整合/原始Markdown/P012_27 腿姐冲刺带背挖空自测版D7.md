# 27腿姐冲刺带背挖空自测答案 D7

1．毛泽东在国民大革命时期，提出新民主主义革命基本思想，标志着毛泽东思想开始萌芽。

2．毛泽东思想初步形成的标志是，在土地革命早期，提出农村包围城市、武装夺取政权的思想并深入阐述。

3．在土地革命战争后期和抗日战争时期，新民主主义革命理论的系统阐述，标志着毛泽东思想趋于成熟。

4．分清敌友，这是革命的首要问题，农民问题是国民革命的中心问题。

5．《中国的红色政权为什么能够存在？》《井冈山的斗争》论证了红色政权能够长期存在并发展的主客观条件，提出了工农武装割据的思想。

6．《反对本本主义》初步界定了中国共产党人的思想路线的基本含义，是独立自主思想的最初的、首次明确表述，初步形成了毛泽东思想活的灵魂的三个基本点，即实事求是、群众路线、独立自主。标志毛泽东哲学思想的初步形成。

7．《实践论》《矛盾论》科学地阐明了党的马克思主义的思想路线。对党的思想路线作了系统的哲学论证。

8．《中国革命和中国共产党》第一次提出了新民主主义革命的科学概念和总路线的内容；《新民主主义论》第一次旗帜鲜明地提出了新民主主义的完整理论，阐述了新民主主义的政治、经济和文化；《论联合政府》进一步把新民主主义的政治、经济和文化与党的基本纲领联系起来，进行了具体阐述。

9．整风运动首先在党的高级干部中进行。《整顿党的作风》和《反对党八股》标志着整风运动在全党范围普遍展开。
